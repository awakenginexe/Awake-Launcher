# Awake Launcher Program Info

This folder contains Awake's application identity, platform assets, and retained
upstream notices:

- Application name and logo (and branding in general)
- Various URLs and API endpoints
- Desktop file

`awake-launcher.png`, `awakelauncher.ico`, and the `io.github.awakenginexe.AwakeLauncher`
platform icons use the maintainer-supplied Awake artwork for version 1.1.0. Windows
icon frames are encoded at 16–256 pixels for executable and installer compatibility.
The PNG and SVG platform variants preserve the same artwork and transparency.

The branding asset license is [CC BY-SA 4.0](LICENSE). The launcher code remains
GPL-3.0-only; see the root [copyright notices](../COPYING.md). Files named for
Prism Launcher retain their upstream attribution and are not the current Awake logo.
