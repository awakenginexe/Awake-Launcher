# Awake Launcher

A general-purpose Minecraft launcher built on Prism Launcher's C++ and Qt engine. Independent instances, mod loaders, Java controls and advanced configuration remain central to the project.

**In development.** The fork foundation is being built and validated; it is not a finished release. No telemetry, advertisements or server lock-in are added.

See [BUILDING.md](BUILDING.md) for build commands, [UPSTREAM.md](UPSTREAM.md) for the pinned revision and maintenance policy, and [the owner brief](docs/PROJECT-BRIEF.md) for product requirements.

Default builds contain no Microsoft, CurseForge or Imgur application credentials. Credential-dependent integrations require Awake-owned configuration. Modrinth and local instance management remain available. The app uses a provisional typographic icon; final brand artwork is pending.

Distributors must provide corresponding source and required notices. The app includes an About / Licenses dialog.
