# Awake Launcher v3.1.0

This is a stable Windows x64 release of the Minecraft launcher. It is the first stable Launcher that can play Awake Modpack Manager projects.

## Play your Manager projects

- **Open a Manager project in Launcher.** Choose **Open in Awake Launcher** on a project in Awake Modpack Manager 1.0.0, or **Link Existing Manager Workspace** in Launcher's library. Launcher plays from the project's own folder and doesn't make a second copy.
- **Your account, Java and playtime stay yours.** Launcher keeps those settings separately and never changes the project's files.
- **Safe while the game runs.** Manager can't change a project's files until Minecraft has stopped, even if Launcher is closed while the game is running.
- Mod installation, pack replacement, export and deletion are turned off for linked instances. Manage their content in Manager.

## Fixes

- Linked projects are now tracked on their actual Windows drive, so projects on a drive other than `C:` work correctly.
- Short overlaps between Launcher and Manager on the same project now wait briefly instead of failing.
- More reliable cancellation and clean-up for downloads and background tasks.

## Connecting Awake Modpack Manager

Launcher only shares a data folder that other Windows accounts can't change. A normal install is always fine. A Compact or Custom data folder on another drive usually isn't private yet: Manager 1.0.0 explains this and offers **Make folder private**. Restart Launcher afterwards.

## Before you update

- **Coming from 3.0.0 or earlier:** Launcher offers this update itself.
- **Coming from 3.1.0-beta.1 or beta.2:** Launcher won't offer it automatically, because the update check treats those betas as the same version. Run the Setup.exe once.
- Your data location and instance folders are kept. No instances are migrated.

The installer isn't code-signed, so Windows SmartScreen may warn. Choose **Setup.exe** to install or update, or **Windows-x64.zip** for portable use. SHA-256 files come with the downloads, along with source archives, licence notices and source instructions. Manager's native helper isn't bundled with Launcher; its source archive is included as source material for the separate Manager release.
