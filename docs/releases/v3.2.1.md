# Awake Launcher 3.2.1

Pairs with **Awake Modpack Manager 1.1.1**.

## Fixed

- **Packs can now connect to the Manager on more PCs.** Choosing **Manage here** could fail with "Windows error 50", then say another program coordinates the instance. Packs installed through the Launcher were affected once a PC had installed more than one.
- **Packs hidden by that error come back.** A failed connect could make the pack disappear from the Launcher. This version restores it the next time the Launcher starts, and your mods and worlds were not changed.
- A file that can't be used safely now shows its name and the reason.

Using Awake Launcher without the Manager still adds no background work.
