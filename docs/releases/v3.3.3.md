# Awake Launcher 3.3.3

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Renaming an instance shared with Awake Modpack Manager now renames its folder even after File Explorer has been inside it.** 3.3.2 fixed this only for ordinary instances; shared ones still failed with "Another program is using the instance folder".

If an earlier rename changed only the name and the folder kept its old name, rename the instance to something else and back.
