# Awake Launcher 3.2.0

Pairs with **Awake Modpack Manager 1.1.0**.

## New

- **Manage your existing modpacks from Awake Modpack Manager.** Turn this on per pack in the Manager, and turn it off at any time. Your files stay in the Launcher's folder.
- **Play from the Manager.** The Play button in the Manager starts the pack in Awake Launcher with your usual account, Java and GPU settings.
- **Instance images in the Manager.** The Manager shows the same image as the Launcher.

## While a pack is managed by the Manager

- It keeps playing from Awake Launcher, and its Java and memory settings stay here.
- Adding, removing or changing its mods happens only in the Manager, so one app at a time changes them.
- Copy, export and delete are off for that pack until you stop managing it.

Every other pack is unaffected, and nothing changes unless you turn this on for a pack.

Using Awake Launcher without the Manager adds no background work: nothing polls or runs while no Manager is connected.
