# Awake Launcher 3.2.3

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Renaming a pack connected to the Manager no longer makes it disappear.** The Launcher used to rename the pack's folder too, and then could not match it to the Manager's record, so the pack vanished from the list while its files stayed on disk. The name now changes and the folder stays where it is.

If a pack already disappeared this way, close the Launcher and rename its folder in `instances` back to the old name. It returns with the new name shown.
