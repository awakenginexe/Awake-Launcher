# Awake Launcher 3.3.1

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **A failed folder rename now says why.** When the Launcher could not rename an instance's folder it only listed the old and new paths. It now gives the reason, most often that another program is using the folder. Windows refuses to rename a folder while a File Explorer window or another program is open inside it; close those and rename the instance again.
- **Message boxes and text prompts no longer show black corners** around their rounded panel.
- **The icon in the update dialog** is now drawn as a proper refresh symbol.

If only the name changed and the folder kept its old name, rename the instance to something else and back once nothing else is using the folder.
