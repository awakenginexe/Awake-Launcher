# Awake Launcher 3.3.5

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Play no longer fails with "A recorded game process is running or its state cannot be verified."** If a game session ended without the Launcher recording that it finished (for example after a crash or a forced close), Play and Modpack Manager changes were refused for that instance from then on. A game session recorded before the computer last restarted is now treated as finished, because a restart closes every game.

## Changed

- **Refreshed Play button.** A round play badge, bolder label and a soft glow, with a light sweep on hover.

If Play is still refused after updating, restart your computer once, then try again.
