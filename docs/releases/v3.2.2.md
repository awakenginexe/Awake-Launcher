# Awake Launcher 3.2.2

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed (in the Manager's helper)

- **CurseForge mods install again.** Installing from CurseForge in the Manager could fail with "CurseForge request failed (HTTP 302)".
- **The same mod from two sites no longer blocks a change.** If a required mod is already in the pack from Modrinth or CurseForge, the identical file from the other site is not added again.
- When two mods really would use the same file, the message now names them.

Nothing in Awake Launcher itself changes, and using it without the Manager still adds no background work.
