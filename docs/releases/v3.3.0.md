# Awake Launcher 3.3.0

Pairs with **Awake Modpack Manager 1.2.1**.

## Changed

- **Every message box and text prompt now uses the Awake popup look.** Questions such as "Would you also like to rename the instance folder?", warnings, errors and the group and world name prompts used to open as plain system windows. They now open as the same dark rounded panel as the rest of the Launcher, with the title inside the panel and the Launcher dimmed behind it.

## Fixed

- **The interface could disappear after the Launcher lost focus or was minimized,** and only came back a moment after you returned to it. The Launcher now redraws its window whenever it is activated, deactivated, minimized or restored. We could not reproduce this ourselves, so please report it if it still happens.
