# Awake Launcher 3.2.4

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Renaming a pack connected to the Manager now renames its folder too.** In 3.2.3 only the displayed name changed, so the folder in `instances` kept the old name. The Launcher now moves the folder and updates the path the Manager saved for it in one step, so the pack stays visible in both programs.

Stop the game before renaming; a running pack keeps its folder name. If a pack's folder still has an old name from 3.2.3, rename the pack to something else and back.
