# Awake Launcher 3.3.4

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Renaming an instance shared with Awake Modpack Manager no longer fails with "A recorded game process is running or its state cannot be verified."** If the Launcher closed or crashed while a game was open, the record of that game session was never finished, and renaming was refused from then on. Renaming now works like Prism Launcher: it is refused only while this Launcher is running the instance, or while a game or another program still has files open in the folder.
- **Mods downloaded with a web browser are accepted by the Manager.** Windows marks those files with where they came from (Zone.Identifier), and the Manager used to refuse them as unverifiable. One instance that still cannot be verified is now listed as needing attention instead of hiding every other instance.

If an earlier rename changed only the name and the folder kept its old name, rename the instance to something else and back.
