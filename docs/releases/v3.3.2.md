# Awake Launcher 3.3.2

Pairs with **Awake Modpack Manager 1.2.1**.

## Fixed

- **Renaming an instance now renames its folder even after File Explorer has been inside it.** Explorer keeps a folder open after you browse it, sometimes even once its window is closed, and Windows refuses to rename a folder while anything inside is open. The Launcher now asks Explorer to let go first. If a different program is using the folder, the rename still stops and says so.
- **Message boxes and text prompts no longer show black corners** around their rounded panel. The 3.3.1 fix did not take effect.

If an earlier rename changed only the name and the folder kept its old name, rename the instance to something else and back.
