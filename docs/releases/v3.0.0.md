# Awake Launcher v3.0.0

This is a stable Windows x64 release of the Minecraft launcher.

- Added local, read-only status and instance/mod discovery for Awake Modpack Manager. Launcher works independently; Manager is not required.
- Improved provider error handling so unsupported requests, malformed responses and early failures report a result instead of leaving a task waiting or accessing an empty failure list.
- Fixed cancellation and restart handling for queued tasks and downloads. Partial downloads are discarded when cancelled or superseded by a cache hit.
- Keep externally owned instances out of native Launcher loading until shared ownership and recovery coordination are supported.
- Corrected application and Windows installer version metadata, including tagged-release display and source commit information.

Microsoft authentication, Java/runtime selection, supported loaders, existing settings and the normal Minecraft launch flow are preserved. Tests use isolated profiles; live account/gameplay behavior is not inferred from fixture tests. No automatic instance migrations are included.

Shared-instance editing/adoption, transactional Apply, and launching through an external Manager are not enabled in this release. The standalone native helper is not bundled with Launcher. Its exact corresponding source for the separate Manager release is available at commit [299c140bd91656cf988efc4cff27887b54ae1efc](https://github.com/awakenginexe/Awake-Launcher/tree/299c140bd91656cf988efc4cff27887b54ae1efc).

Startup performance depends on profile size and Windows background activity. Prior measurements of the experimental integration branch showed a small median increase and an unexplained outlier; those results are not a measurement of this reduced stable composition. This release makes no claim of zero startup regression.

Choose **Setup.exe** for installation/updates or **Windows-x64.zip** for portable use. Keep your current data-location and instance folders; the installer preserves existing data settings. SHA-256 files accompany the downloads. Source archives, licence notices and source retrieval instructions are included. The helper-source archive is source material, not an additional Launcher feature.
