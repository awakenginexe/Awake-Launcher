# Translation sources

Imported from PrismLauncher/Translations revision `86470aacf6f9b66315ab2ecf302b5b84a23b92da` (2026-10-03). License: see LICENSE in this directory. Translator attribution is retained in the TS message metadata and upstream history.

English is the source language. Awake ships only Thai (`th`), Simplified Chinese (`zh_CN`, upstream `zh`) and Traditional Chinese (`zh_TW`). Upstream product-name strings are adapted to Awake Launcher. Catalogs compile during the CMake build; no online translation catalog is fetched by default.

Thai upstream coverage is partial. Untranslated strings fall back to English. Index percentages reflect the upstream index snapshot, not a claim of complete Awake translation. Newly added Awake contexts are maintained in these TS sources.
