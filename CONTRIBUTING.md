# Contributing to Awake Launcher

Keep changes focused, follow the style of nearby code, and preserve upstream copyright and license notices. Format C++ changes with the repository's `.clang-format` file. Do not include credentials, account files, instance data, or local build artifacts.

Before opening a pull request:

- Describe the user-visible change and why it is needed.
- Build and run the relevant tests. List any platform or runtime checks you could not perform.
- Sign off your commits using `git commit -s`. This confirms the Developer Certificate of Origin below.

For build requirements and commands, see [BUILDING.md](BUILDING.md). Please report bugs through [GitHub Issues](https://github.com/awakenginexe/Awake-Launcher/issues).

## Developer Certificate of Origin 1.1

By signing off a commit, you certify that you created the contribution or have the right to submit it under the indicated open-source license; that you have permission to submit any prior work it contains; and that you understand the contribution and sign-off are public and may be redistributed under the project license. Read the [full certificate](https://developercertificate.org/) if you need its exact wording.
